12. Diseña una integración empresarial completa. 20 pts

RESET implementará una solución para una empresa que utiliza un CRM, un sistema externo de facturación y una base de datos de clientes. Cuando una oportunidad pasa a GANADA se debe:

  1. verificar si el cliente existe en facturación;
  2. crearlo si no existe;
  3. crear una factura;
  4. obtener el número de factura;
  5. guardar ese número en el CRM;
  6. notificar al equipo cuando ocurra un error.

Tu respuesta debe cubrir flujo de información, prevención de duplicados, manejo de estados parciales, seguridad de credenciales/tokens, trazabilidad y al menos una decisión técnica con ventajas y desventajas.
